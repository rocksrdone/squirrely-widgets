Dye station — every batch

Same five steps every time. Anything unusual is on the back.

1

Pull the tag, pick the colorway

Tags are in plan order — take the top one. Check the colorway on the tag is what you're about to dye.

Morning Batch Planning

Click that colorway in the list. Batch Assignment fills in on the right.

2

Dye it

Tie colours as usual — red ties = 10 spools.

3

Log the pot

Batch Assignment → Log a pot

  • Type the spool count into Spools this pot
  • Choose Keep for orders normally, or All to back stock if none of it is going to a customer
  • Click ✓ Log pot
The lot number flashes up in the message at the bottom. Write it on the tag before it fades. If you miss it, it's the newest lot for that colorway in Production Lots.

Hand-dye colorways: one pot = one lot. Log each pot separately, each gets its own tag.

4

Answer the cleanup questions

Batch Assignment → After you finish — dye cleanup

One dropdown per dye: What did you do with the leftover? Answer each one. It tells you which bin, and whether the dye is wanted again today — that's what keeps the prep table from filling up.

5

Bag the tag, rack the thread

Tag into a zip bag, ring it to the rack bar beside its hank. Dye must not reach the paper — that tag has to still be readable in six months.

Already on the tag

Bag code · colorway · SKU · fiber · planned spools · who it's likely for · photo needed or not.

Nothing on it is binding. It's the plan, not a promise. Cross anything out that changed.

You write

Lot number — every time, from step 3.

Bin — when it goes in one, after it's dry.

Note line — anything odd. Free text, no rules.

The one rule

You never decide who gets what. That happens at control, with the thread in front of them. Ticking likely for is a suggestion for them, and it costs nothing to be wrong.

When it isn't a normal batch

Find the situation. Do those steps instead of, or on top of, the five on the front.

It came out wrong

Unrecognisable as the colorway. Bleeding, wrong shade, a mistake at the pot.

  1. Tick LE on the tag
  2. Write why on the note line — this is the record you'd need to repeat it or avoid it
  3. Cross out the colorway name. It's a lie now.
  4. Log the pot as normal, but pick All to back stock
  5. Bin the sheet. Those orders aren't getting this thread — they go back in the queue on their own

Tag stays with the thread. Control names it later. The order still needs dyeing another day.

Still good, just not right

Nice thread, wrong for the order. Not a mistake — just not what was promised.

  1. Don't tick LE. It isn't one.
  2. Note what happened on the note line
  3. Log the pot, All to back stock
  4. Bin the sheet

Goes to back stock under its own colorway. The shop takes almost everything.

Leftover dye, making something random

Using up what's in the pot. No plan, no order, might be nice.

  1. Click 🎨 New colour draft — get a code in Batch Assignment
  2. A big code appears — DR-260805-1. Write it on a spare tag
  3. Write the dyes and rough amounts on the note line. Only you know these.
  4. Tick photo — a new colour always needs one
  5. Leave likely for blank

Don't log a pot for it. The button already made the lot. Logging again gives you two lots for one bag.

A new colour you planned

Deliberate. You designed it and want to be able to make it again.

  1. Same button, same code, same spare tag
  2. Write the dye amounts carefully. This is the whole point — you can't reconstruct them later
  3. Tick photo

If you built it in Quick Draft beforehand, use that code instead and skip the button — you already have a lot.

This pot won't finish the order

A 20-spool order needs two lots.

  1. Tick combining on the tag
  2. Write which order on the note line
  3. Log the pot as normal, Keep for orders

Control holds it in the partner bin until its match arrives. It won't ship half-done.

No tag for what you're dyeing

A redo, an extra pot, something you decided on at the kettle.

  1. Take a spare tag — it already has a bag code
  2. Write colorway, and lot number after you log the pot
  3. Tick likely for only if you know. Blank is fine.

Spare codes never collide, even weeks later. Use as many as you need.

You broke a spool or came up short

38 in the bag when the tag says 40.

  1. Log the pot with the real count, not the planned one
  2. Write it on the note line

Don't work out who goes short. Control does that with the thread in front of them.

Photographing a wet hank

LE or a new colour, before it dries.

  1. Lay the tag beside the hank, code readable
  2. One shot. Phone is fine.

This is a working record, not a product photo. The real one gets taken dry, at control.

If none of these fit — write what happened on the note line and let it go to control. A confusing tag they can ask you about beats a wrong one they can't.
